# OpenMTP 4.0.0-beta.1

OpenMTP now uses SwiftUI and a Swift MTP engine. The native app replaces the Electron application.

- Browse Mac and phone folders side by side in list or grid views.
- Copy files and complete folder trees, including empty folders. Queue transfers, cancel work, and retry after reconnecting.
- Choose skip, replace, keep both or Smart Sync when items already exist. Destination extras require a separate confirmation before removal.
- Use Finder file promises, Quick Look, native menus, keyboard commands and saved preferences.
- Use Liquid Glass controls on macOS 26 and later, with accessibility fallbacks. The app supports macOS 13 and later.
- Install signed native updates through Sparkle when release signing and update keys are configured.

This prerelease needs real-phone transfer, reconnect and cancellation checks. Ad-hoc developer builds use manual update downloads and are not notarized distribution builds. See PARITY.md and VALIDATION.md for evidence and remaining checks.
